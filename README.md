# GameSuite

Mobile-first React + TypeScript app scaffolded with Vite, TailwindCSS, Zustand, React Router, lucide-react, and PWA support.

Quick start

1. Install dependencies

   npm install

2. Run dev server

   npm run dev

3. Build

   npm run build

4. Preview build

   npm run preview

Tests

  npm run test

PWA

After running the dev server or serving the built app, open DevTools > Application to inspect the service worker and manifest. To install on mobile/desktop, use the browser's install prompt (usually available in the address bar or via the app menu).


## How to run
- npm i
- npm run dev

Routes: /splash, /auth, /home, /channels, /games, /profile, /uno/lobby, /uno/game, /uno/results

PWA: autoUpdate SW, offline fallback, add to home screen on mobile.
